# 初回公開手順

対象：`peridotan/authentication-explorer`、`v1.0.0`（公開用ファイル）。基準は `v0.9.0-rc3`。所有者はMITライセンスと正式公開への移行を承認済み。公開リポジトリは作成済み。GitHubへの反映は未実施。

## 公開前ゲート

- [x] 01・02の仕様確定、ソースの技術レビュー。
- [x] v1.0.0版表記、README、変更履歴、MIT LICENSEの反映。
- [x] v1.0.0同梱テスト2本の独立実行（詳細はQA-REPORT.md）。
- [x] 参考リンク確認（rc3時点）、PC・モバイルの代表操作確認（rc3時点）。
- [x] 所有者のMITライセンス・公開移行承認、リポジトリ作成と権限確認。
- [ ] 全256 STEPの個別実描画目視。未検証なら制約として報告し、未検証のまま公開する場合は所有者の判断を仰ぐ。
- [ ] 重大・中程度の問題があれば修正して回帰テストを再実施。機能追加は行わない。

## GitHub Pagesへの反映

1. 対象リポジトリの現在の状態を取得する。空なら初回コミットとして公開用ファイルを `main` に一括反映する。既存ファイルがある場合は内容を確認し、独断で上書きしない。秘密情報や作業用ファイルを含めない。
2. QA用GitHub Actionsが成功したことを確認し、実行URLとコミットSHAを記録する。失敗・実行不能の場合は原因を報告して公開設定を保留する。
3. Settings → Pages → Build and deployment で `Deploy from a branch`、`main`、`/(root)` を選ぶ。Pagesデプロイの成功を確認する。
4. 公開URL https://peridotan.github.io/authentication-explorer/ を実ブラウザーで開き、版表示、01・02、再生操作、比較表からの往復、正常系比較、テーマ・文字サイズ、参考リンク、JavaScript例外を確認する。QAレポートに確認範囲・結果・未確認事項を追記する。
5. 公開サイトの確認結果を報告し、所有者の承認後に `v1.0.0` のタグとGitHub Releaseを作成する。

公開対象は01・02のみ。詳細な認証プロトコルの追加、03・04の再導入などの機能追加は行わない。
